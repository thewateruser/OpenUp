### New: back up to a USB drive
- **Settings → Backup location → Back up to a USB drive**: pick the drive in the system folder picker and
  all backups go into an `OpenUp` folder on it instead of the phone's storage.
- Backup files larger than 2 GB are split into parts, so drives formatted as FAT32 (most USB sticks) work.
- If the drive is unplugged, backups stop with a clear message, the home screen shows a warning, and
  scheduled backups skip that run.
- Phone storage is still available as a location; existing backups are not moved.

Verify the download with `SHA256SUMS.txt`. The APK is signed with the same key as 1.0.0, so it updates
the installed app in place.

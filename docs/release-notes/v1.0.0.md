First release of **OpenUp**, a free and open source backup app for Android that uses
[Shizuku](https://shizuku.rikka.app/) instead of root.

### Backs up and restores
- **Apps**: APKs including split APKs (installed silently, many apps at once), external data
  (`Android/data`), expansion files (`Android/obb`) and media (`Android/media`).
- **Permissions & app settings**: runtime permissions, usage access, accessibility services,
  battery optimisation and other special access.
- **Messages**: SMS, MMS with attachments and RCS, including end-to-end encrypted RCS chats on
  Android 17, without making OpenUp the default SMS app.
- **Call logs**, **wallpapers**, **saved Wi-Fi networks with passwords** and **any folder**.

### Also
- Scheduled backups, backup versions, Zstandard compression and AES-256 password encryption.
- Checksums are verified on restore, and data is only replaced after a backup was read completely.
- No internet permission.

### Requirements
- Android 8.0 or newer and Shizuku (started via Wireless debugging or adb).
- Private app data (`/data/data`), notification settings and the SSAID need root and are not included.

### Notes
- This is the first release; please report problems in the issue tracker.
- Verify the download with `SHA256SUMS.txt`.

### Fix
- Restores of app data (and folders restored through Shizuku) now wait until OpenUp has confirmed that the
  whole backup file was read correctly, including its final checksum, before the existing data is
  replaced. Previously, a damaged file that was neither compressed nor encrypted could replace the data
  before the problem was noticed.

Verify the download with `SHA256SUMS.txt`. Signed with the same key as earlier versions, so it updates the
installed app in place.
